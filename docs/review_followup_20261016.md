# 新稿外部评审与后续优先级

paperreview.ai 的 Stanford Agentic Reviewer 已对本轮 PDF 返回 ICLR 标尺估分 4.5/10，倾向拒稿。这是外部 AI 评审估分，不是会议录用决定，也不是比赛总分；未取得比赛 40 分项换算规则，暂不换算。独立论文评测 Agent 的 20 分项尚无结果。

本轮交付包保存完整网页评审、私有访问 Token、送评回执和对应 PDF 的 SHA256。评审认可 Rail 的可复用接口、时间过滤的确定性、证据与答案的分离、冻结协议及完整 token 计账。主要缺口是样本规模小且全为合成记录，缺少语义检索与真实外部基准，冲突保留没有带来已观察到的准确率增益。原始评审保持原文，不把内部修订写回评审。

评审中的“single seed”需要限定：本轮留出数据来自 1729、2718 两个生成种子命名空间，但每个条件只有一次模型回答，没有跨模型或重复运行。因此，多次模型运行和多数据种子的稳健性证据仍然不足。评审推荐的额外论文和数据集名称尚未核验，不能直接加入参考文献。

下一轮优先补论文质量的证据。先离线分析 recent 的零正确率与 full 的错误案例，核验并接入一个适合时间更新任务的外部基准，再添加 embedding 或混合检索对照。之后单独检验冲突感知回答或拒答是否能利用完整冲突组，以及替代预算分配规则是否优于当前贪心装包。所有新增比较先冻结协议和成本上限，再调用 API，不依据留出答案调整算法。

系统与资源两项继续保留现有可追溯工件、恢复机制及实际用量账本，并将新基准适配器与通用 Rail 接口整理为可审阅的上游贡献。当前已提供 patch 和文档，尚无上游 PR 或合并；不将预计分数当作实得分数。本次版本完成后未为下一轮自动追加付费实验。
