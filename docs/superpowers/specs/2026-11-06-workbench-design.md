# 科研工作台设计

用户已批准：工作台使用中文，论文、摘要、图表标题和学术导出保持英文。第一版读取真实产物，支持查看、筛选、对比与下载，不从页面发起付费实验。

采用独立 React / TypeScript / Vite 前端与 Python 标准库 HTTP 服务，不修改上游界面。构建后由同一个本地服务提供页面与 API，仅绑定 127.0.0.1。开发时 Vite 代理 API。现有实验和送评 PDF 保持原始字节。

四个导航页：总览显示研究流程、主条件比较和当前版本；实验中心按 split、budget、policy、正确性与关键词筛选，查看原始回答、参考答案与所选证据；论文评审展示英文 PDF、原文评审及独立标注的中文解读；资源交付展示实际总账、预算准入阈值与文件下载。比赛 60/15/10/15 为评分权重，不推断实得分。外部 4.5/10 单独标明估分，不映射为比赛分。

服务根据 output 中真实 manifest 注册运行，不接受任意路径。文件下载使用明确工件 ID 白名单，拒绝遍历和符号链接逃逸。不暴露配置、API Key、请求日志或私有评审 Token；私有提交 ZIP 的下载仅供本机使用，并在界面提示。缺文件、格式错误、连接失败和空筛选结果均有明确状态。页面只读，不执行 shell 或模型 SDK。

验证包括数据聚合与缺失状态测试、白名单/遍历/未知运行 HTTP 测试、生产构建、真实 API 集成检查和桌面/移动浏览器交互检查。保留现有未提交研究文件，不做无关重构。
