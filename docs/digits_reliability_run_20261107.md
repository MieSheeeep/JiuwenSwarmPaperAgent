# 全新手写数字可靠性研究：真实运行记录

论文：Clean-Validation Confidence Thresholds Do Not Transfer to Corrupted Handwritten-Digit Recognition。

本地 PDF：`output/framework_digits_20261107/workspace/paper/paper.pdf`，8 页，4016 个英文词，两张来源于实验数据的图和一张指标表。SHA-256：`4319acbec94d360650d5d2ec5265cfd153f13a527e330d059ce317d70a34b53c`。

这是用户选择的新研究方向：手写数字在图像干扰下的可靠性和拒答。新数据划分、新训练权重、新预测、新分析；没有读取旧 QA 研究结果。旧模型权重、旧回答、旧论文均未复用。

## 研究问题与方案

问题是在清晰图片上选定、以回答 80% 图片为目标的阈值，能否在噪声或像素缺失后保持其工作状态。该问题属于机器学习的不确定性和图像识别研究，与 ICLR 的征稿范围相关。方向已经有大量工作；本研究是小规模新测量，不是新算法，也不证明达到正式 ICLR 录用水平。

官方范围：https://iclr.cc/Conferences/2026/CallForPapers

先固定的设计见 `docs/superpowers/plans/2026-11-07-digits-reliability.md`。代码及设计在查看测试结果前提交为 `bd88e9c`。使用 sklearn 自带的 UCI 8x8 digits，**不是 MNIST**。1797 张图片按 seed 20261107 分层划分为 1077 训练、360 验证、360 测试；未验证 writer-group 隔离。

MLP 为 64 输入、64/32 隐层、10 类输出，ReLU、Adam、学习率 0.001、alpha 0.0001、batch 64、固定 200 轮、禁用早停。5 个初始化种子 11/23/37/51/71 从头训练，CPU 两个 BLAS 线程。三轮的小 pilot 仅用训练和验证集验证接口，最终模型重新初始化训练。

四种置信分数为最大概率、温度缩放后最大概率、最大两个 logit 的差、负熵；另有全部回答基线。温度仅使用验证集 NLL 拟合；阈值仅由清晰验证集分位数决定，主目标 80%、次目标 90%。测试扰动为清晰、Gaussian sigma 0.15/0.30/0.45、像素 dropout 0.10/0.30/0.50。像素先除以 16 归一化到 [0,1]，每种扰动只取一次预定实现，所有模型共用。

## 新测量结果

下表为五个模型均值；拒答行为由清晰验证集的 80% 目标阈值决定。

| 图像条件 | 全部回答的错误率 | 最大概率拒答后的回答比例 | 接受图片中的错误率 |
|---|---:|---:|---:|
| 清晰 | 2.89% | 78.61% | 0.21% |
| Gaussian sigma 0.30 | 19.39% | 40.89% | 1.75% |
| Dropout 0.30 | 23.50% | 32.89% | 2.52% |

拒答有效降低接受集内的错误，但回答比例在干扰下明显下滑。因此不能把清晰验证集的目标回答比例当成受扰测试环境中的保证。四种分数在这个实验中表现接近；温度缩放不能在本设定中恢复原工作点，但不据此推断它在所有任务上无用。

共保存 35 组模型×图像条件的 test logits，实际产生 12,600 次本地分类预测和 315 个模型×条件×策略/目标评估单元。315 不是独立测试图片数；独立图片索引只有固定的 360 个。五种初始化共用相同划分和扰动；SD 描述初始化波动，不是独立数据集置信区间。

## Flash 消耗与干预

写作/文献/审查共 6 次 Flash provider 调用，84,129 tokens，低于本研究单独设定的 100,000 token 上限。实际 provider usage 的 model_name 全部为 deepseek-flash，没有 v4pro。请求与响应 ID 完全对应，用量已核对。接口返回的 cost 字段不作为真实账单。

过程不是无人干预的一次成功运行：

1. 第一次全文审查要求修正数值分组与推断措辞。重复全稿生成被保守预算预留机制阻止，发生在发送请求之前，因此没有这次重试的费用。
2. 保持预算不变，改为模型定点修订 Results/Discussion，再进行明确标为 focused follow-up 的后续审查。Flash 判为接受。
3. 操作者源码核对又发现模型将 accuracy 描述成 error rate，以及声称温度缩放必然保持跨样本 MSP 排序。修正为正确率定义，并区分“单个样本 argmax 类别不变”和“不同样本置信分数排序可以改变”。补充像素归一化、噪声尺度、划分种子和全测试集 NLL/ECE 口径。修正没有额外 API 费用，没有改变任何实验数值。
4. arXiv 元数据使用 family,given 顺序，渲染器原先错误地用 given name 做引用标签；修复显示格式，保留真实作者身份与顺序。

最终 workflow 的 review 记录为操作者对上述更正的源码一致性签核，并保留此前 Flash 审查历史。它不是新一轮独立冷审查，更不是 ICLR 或其他外部同行评审通过。PDF 使用 ICLR 风格排版，不代表投稿资格或已投稿；没有上传任何外部平台。
