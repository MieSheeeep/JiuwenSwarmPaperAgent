# 升级版匹配评测协议

2026-11-06：用户批准本轮模型 API 输入与输出合计 3,000,000 Token 准入上限，包含回答、反思、评测、修订和写稿。此上限不是供应商硬计费上限。实验预留 150,000 Token 给后续写作，并逐调用核对实际 usage；未知用量、模型条件漂移或调用契约失败会停止新增调用。

新协议使用三个新的合成测试种子及独立开发种子。合成主测试 72 例、装包压力 12 例，另有 16 个开发任务。外部为固定来源与哈希的 LongMemEval 清洗版 500 题，预先分层抽取 70 题用于双模型、三检索方法的匹配比较；完整 500 题的主方法覆盖另行汇总，不与 70 题对照混合。

统计模块 research/upgrade_analysis.py 只比较相同任务、条件、阶段和集合中的有效完成结果。主比较使用 repeat=0；重复调用是稳定性诊断，不扩充独立样本量。预算与重复比较仅允许协议列明的阶段桥接。外部词法精确匹配与 DeepSeek 改编语义评测分别报告，均不冒充官方基准成绩。

报告配对成功/失败、任务 ID 哈希、排除项、固定种子的任务重采样描述性区间、McNemar 精确二项诊断及按比较族的 Holm 校正。生成器、种子、任务类别和外部历史可能相关，独立性未验证；代码不会自动许可显著性或泛化声明。按 family 与 source_seed 提供分层诊断。

所有新输出位于 output/review_upgrade_20261106/，原始实验、旧送评稿和旧评审 Token 保持独立。代码实现、模型实际调用、有效对照、科学结论与外部评分分别标注，不将某个源文件存在视为评审缺口已经解决。
