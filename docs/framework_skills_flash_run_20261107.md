## 真实干预与局限

本轮不是无人干预的一次成功运行：

1. 初稿约 3089 词，章节检查因 Methods 被命名为 Task, Data, and Protocol 而失败。补充标题别名后复用已保存响应，没有重复付费生成初稿。
2. 首次审查响应被截断。已计入费用，核对账本后缩短意见格式、移除模型上下文中无助审查的重复哈希；完整原始行仍保存在分析材料里。
3. 五个审查视角和汇总均使用同一 Flash 后端，并不是五个独立模型。离线复算正确，但模型错误地声称自适应均值不对，还提出“零分文档能排在正分文档前”的不成立意见。汇总模型也没有可靠地排除这些误判。不能把模型意见当成事实。
4. 流程生成了约 3772 词的修订稿。随后一次来源约束的定点修订仍把 BM25 基线与生成的词重合函数混淆。操作者依据实际源码纠正两者，明确 substring count、排序、token normalization、模型标识和样本来源；未改动算法或实验结果。
5. 删除论文中不参与论证的 React Hooks 领域引用，保留其原始检索记录；补上三项实际使用来源的正文引用。修正案例仅存在于分析附件、而非已经展示在正文的表述。
6. 全文共七页，已逐页检查。长哈希换行、待审稿标记及文档均值的小数精度在渲染器中得到修正，最终编译无 Overfull 警告。

为了避免错误审查引起连续付费重写，完成当前修订后停止自动循环。**最终稿没有完成新一轮五视角冷审查，没有内部通过结论，没有外部评审或官网提交。** PDF 清楚标注 final internal review pending。源码核对属于人工参与，不冒充模型独立审查。
